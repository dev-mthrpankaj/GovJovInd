Official Rules

Top 3 Prize, Fee, Timing & Eligibility Rules

These rules apply to GovJobUpdates Live Test competitions unless a test-specific notice or admin setting says otherwise.

1. Top 3 Prize Money Rule

For paid Live Tests, base prize money is calculated from the valid registration value of that test.

Rank 1 gets 40%, Rank 2 gets 20%, and Rank 3 gets 10% of the valid registration value.

Payout is released only after result verification, leaderboard eligibility check, anti-cheating review and payment/admin verification. Eligible Rank 1, Rank 2 and Rank 3 winners receive the payable amount according to the final verified calculation.

If GovJobUpdates displays or announces any prize above this base split, the extra amount will be treated as a promotional offer/bonus and may be subject to test-specific terms, seat conditions, verification and admin approval.

Free registrations, promo discounts, failed payments, cancelled entries, refunds and admin verification can affect the final payable collection and prize calculation.

2. Entry Fee Rule

Entry fee is not fixed for every test. The admin can make a test free or set a different fee for each paid Live Test. The current fee will be clearly shown before registration and payment.

3. Promo Code Rule

Promo codes may be public, limited-use, test-specific or time-limited. A valid promo may reduce the payable amount or make the registration free. Some tests may also have an automatic free-pass offer for early confirmed registrations.

Promo validity does not override registration timing, seat limit or anti-cheating eligibility rules.

4. Registration & Login Timing

Registration window is set separately for each test by the admin. The exact start and end date/time is shown on the Live Test portal test card. Candidate login opens 10 minutes before the scheduled test start time.

Candidates should login early, read instructions and keep their device/internet ready before the test begins.

5. Test Pattern

Live Test pattern is configured per test. Questions, sections, duration, timer mode, marks per correct answer and negative marks can be changed from the admin panel.

Sectional or full-paper timer Dynamic sections and questions Default marking: +1 / -0.25 Subject language rules apply Pattern shown before test

6. Tie-Breaker Rule

If two or more candidates get equal marks, ranking/winner will be decided by this order:

  1. Higher total marks
  2. Higher correct answers
  3. Higher accuracy
  4. Earlier submission time
  5. Final admin decision in exceptional/dispute cases

7. Anti-Cheating & Disqualification Rules

Tab switching, app switching, repeated refresh, abnormal browser activity, copy/right-click attempts, suspicious reloads, multiple warnings or other unusual activity may be logged by the system.

A suspicious/disqualified candidate may be removed from leaderboard and prize eligibility. GovJobUpdates admin decision will be final in cheating/dispute cases.

8. Payment, Cancellation & Refund Note

Only successful payments/valid free promo registrations are counted for confirmed registration. Failed, pending or cancelled payment entries do not confirm a seat.

In case of technical or payment dispute, candidate should share Registration ID, mobile number and payment details for verification. Refund handling follows the GovJobUpdates Refund Policy.
