Before uploading documents to official portals

  • Always confirm exact file size, dimensions and format from the official notification or portal.
  • Preview the final file before upload to check clarity and orientation.
  • Some PDF features use browser libraries loaded from a CDN. Keep internet active while using these tools.
  • On some mobile app/WebView devices, if direct download does not start, open the page in browser and download again.
  • Keep original files safe until your application is accepted.
