About This Admit Card

UPSSSC has issued an update for candidates shortlisted for the main examination. The notice states that advance information regarding the examination district has been uploaded on the Commission website.

This update is not the main examination admit card. The notice clearly says that candidates will be informed separately through the website about the issue of admit card, and a valid admit card will be mandatory to appear in the main examination.

Candidates should first complete the prescribed main examination fee process because the notice states that the district advance information and admit card can be downloaded only after depositing the prescribed fee.

How to Download Admit Card

  1. Visit the official UPSSSC website at upsssc.gov.in.
  2. Open the relevant link under the Examination Segment on the home page.
  3. Login with the details required by the official portal.
  4. Pay the prescribed main examination fee if it is pending.
  5. Download the exam district advance information and later download the admit card when released.
  6. Verify exam date, centre, reporting time and instructions from the official admit card.

Details Mentioned on Admit Card

  • Candidate name and registration details.
  • Exam name and stage.
  • Exam date and shift, if printed.
  • Exam centre and reporting time once admit card is released.
  • Photograph, signature and identity details, if printed.
  • Main examination instructions issued by UPSSSC.

Documents to Carry

  • Printed valid admit card once released.
  • Valid photo identity proof.
  • Passport size photograph, if instructed.
  • Fee receipt or application acknowledgement, if required.
  • Documents mentioned in the official admit card.

Exam Day Instructions

  • The district advance information is not the admit card.
  • Appear in the main exam only with a valid admit card.
  • Pay the prescribed main exam fee before viewing district information or admit card.
  • Check UPSSSC website regularly for admit card release.
  • Follow all instructions printed on the official admit card.

Duplicate Admit Card / Correction Instructions

The provided notice does not mention any duplicate admit card or correction schedule. Candidates should check the UPSSSC website for admit card release, correction and helpdesk instructions.
