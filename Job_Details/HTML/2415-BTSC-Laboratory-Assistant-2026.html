General Exam Pattern Framework

  • Question Base Type: Multiple Choice Questions (MCQ) set in an online CBT mode.
  • Total Exam Duration: 2 Hours (120 Minutes continuous timing).
  • Marking Layout: 1.0 point added for a correct answer; 0.25 point deducted for an incorrect response.
  • Syllabus Focus: Basic General Knowledge and General Awareness along with deep structural domain questions based on the candidate's core Engineering Diploma / Science Degree specializations.
