About This Answer Key

The Uttar Pradesh Education Service Selection Commission has published the provisional master set answer key for the Trained Graduate Teacher recruitment written examination. A provisional answer key is an initial official answer key that candidates can check before the final answer key and result process.

The response login helps candidates compare their attempted answers with the provisional master set answer key. This is useful for self-analysis and for identifying any question or answer that may need to be challenged through the official online objection link.

The objection window is important because the commission will consider only objections submitted through the notified online mode and within the given time limit. Candidates should read the official instructions carefully and avoid relying only on unofficial screenshots or social media updates.

How to Download UP TGT Answer Key

  1. Visit the official UPESSC website at upessc.up.gov.in.
  2. Open the UP TGT 2022 provisional answer key or objection link available on the website.
  3. Login through the online portal using the required details mentioned in the notice.
  4. Check the master set provisional answer key for your subject.
  5. Compare the answer key with your attempted answers and save the details for personal analysis.

How to Raise Objection

  1. Open the official objection login link during the objection period.
  2. Login by entering your Roll Number and Date of Birth as mentioned in the official notice.
  3. Match your answers with the provisional master set answer key carefully.
  4. Select the question or answer for which you want to submit an objection.
  5. Upload or enter supporting proof if the official portal asks for it.
  6. Check the portal for any objection fee or final submission requirement before submitting.
  7. Submit the objection online before 12 June 2026 up to 12:00 midnight.

The notice clearly says that objections received through any medium other than the online link will not be considered.

How to Calculate Expected Marks

The provided answer key notice does not mention the detailed marking scheme, negative marking rule or score calculation formula. Candidates should check the official exam scheme before calculating expected marks.

  • Use only the official provisional answer key for answer matching.
  • Check the official UP TGT exam scheme before adding marks or applying negative marking.
  • Do not treat expected marks as final result because objections and final answer key review can change the final evaluation.
